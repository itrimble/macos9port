# OS999 development dashboard

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Confirmed by Ian: local Python service and browser UI. Build directly in code.

## Users

Ian, a visual thinker monitoring OS999 development and integration across local
worktrees. The opening view is feature parity with the latest build visible.

## Product Purpose

Make project state, missing features, compatibility, evidence, performance and
build progress understandable at a glance, with drill-down to source evidence.
Automatically refresh as source checklists, Git state and build receipts change.

## Capabilities and Constraints

Localhost service, no external publication. Include completion donuts, animated
milestone timeline, Mermaid Gantt, compatibility scatter plot, benchmark bars,
System Folder treemap, searchable checklist and alerts. Automatic milestone
builds use explicit-ready integration submissions and unique ascending numbers.
Preserve the ongoing complete-build integration effort and dirty producer trees.

OS999 is currently a clean-room userspace desktop and runtime, not a kernel.
Mac OS 9.2 feature parity is the target, not an achieved claim. Missing baseline
measurements, estimates and acceptance evidence must remain explicitly unknown.

## Brand Commitments

Professional dark-mode technical aesthetic, subtle glowing accents, smooth
transitions, clean navigation and visual explanations. No invented benchmarks.

## Evidence on Hand

Repository development checklist, master tracker, source snapshots, Git branches,
local build/test logs and historical receipts. Existing historical reports are
distinct from newly observed results. No verified Mac OS 9.2 benchmark dataset
has been supplied.

## Product Principles

- Show accepted, implemented and pending work separately.
- Every progress claim links to its source or evidence.
- Surface stale data and failures rather than hiding them.
- Build automation preserves the last passing artifact and never pushes.

## Accessibility & Inclusion

Keyboard-operable filters, text alternatives for charts, status labels in
addition to color, reduced-motion support and responsive layout.
